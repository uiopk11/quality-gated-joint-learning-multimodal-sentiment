# 基于质量门控与联合学习的多模态情感预测模型

面向复杂场景下的多模态情感预测，项目包含从原始视频特征提取、局部模态缺失下的鲁棒预测，到冻结模型解释与原素材证据回溯的完整实现。输入为文本、语音和视觉，输出为负向／中性／正向情感极性及连续情感强度。

本仓库由竞赛开发工作区与最终交付代码整理而成。保留核心实现、固定实验协议、预测结果、建模说明和可追溯记录。完整版论文按用户要求暂不上传。原始竞赛数据与大模型权重需另行准备。

## 方法

- **QG-HTA：质量门控分层词元对齐。** 官方文本进入冻结BERT；Whisper用于辅助核验；根据文本—语音一致性及首尾锚点选择完整MFA、窗口化MFA、局部ASR时间戳或无词级对齐。OpenSMILE/OpenFace分别提供74维声学与35维视觉特征，保留质量掩码。
- **JPI-DLFR：极性—强度联合预测与双层特征恢复。** 使用BERT、音视频LSTM及EMT交互；在完整与固定局部缺失双视图下联合训练分类、回归和恢复目标。最终附件3预测使用M3 seed854。
- **冻结M1的双目标解释。** 枚举8种模态保留组合计算精确Shapley，结合多尺度连续窗口遮蔽和随机删除忠实度验证；QG-HTA把可信证据回溯到原始视频时间。解释表示相对于遮蔽基线的模型敏感性。

问题1自主特征维度与题目标准特征接口一致，但不能宣称两者字段语义或数值完全相同。问题2/3使用官方标准特征；问题3使用M1，不能替换为问题2的M3。

## 快速开始

需要Python及各模块单独记录的依赖。原验证环境以Windows为主；问题2为Python3.12/PyTorch2.8.0+cu128，问题1和问题3采用各自环境文件。不要把三套版本锁定文件直接混装到一个环境。

### 1. 查看已保存的结果

- 问题1：[100条统一特征](问题1/问题1_100条多模态时序特征.pkl.gz)，按[问题1说明](问题1/README.md)读取。
- 问题2：[附件3预测](问题2/附件3_测试集预测结果.csv)，30条，M3 seed854单模型。
- 问题3：[附件4预测与解释](问题3/附件4_测试集预测与解释结果.csv)，20条、104列，使用冻结M1 seed1111。

无需训练即可阅读CSV、JSON和SVG。载入特征归档需要NumPy；预测需另行准备权重、BERT及官方输入。

### 2. 检查仓库副本

在仓库根目录运行（只需Python标准库）：

```powershell
python -X utf8 scripts/verify_repository.py
```

该检查核对保存文件SHA256、所有Python文件语法、30/20条预测覆盖及关键帧引用；不等于模型重训练或完整实验复现。

### 3. 复现附件3预测

进入`问题2/`，按[问题2 README](问题2/README.md)安装依赖并准备权重和官方附件3。使用随包运行入口：

```powershell
python -B -X utf8 run.py predict --help
```

完整命令、输入校验、GPU/CPU选择与参数以该模块README及`--help`为准。修改实验时采用新配置、新run名称和新输出路径，保留已保存结果。

### 4. 复现附件4解释

进入`问题3/`，按[问题3 README](问题3/README.md)安装独立环境、放置M1/BERT，并设置`E_TOPIC_DATA_ROOT`：

```powershell
$env:E_TOPIC_DATA_ROOT = 'D:\官方数据\E题数据'
python -B src/audit_attachment4.py
python -B src/run_attachment4.py --device cuda
python -B src/run_fidelity_validation.py --device cuda --random-repeats 10
```

秒级回溯还需要问题1工具链与`Q1_RESOURCE_ROOT`。完整顺序见复现指南。

## 结果与限制

已保存的问题1审计记录为100条结构检查全部通过；问题3附件4忠实度记录为354组有效比较中95.48%不弱于随机删除。附件3/4均无标签，不报告其准确率。

论文的多种子均值、旧Accuracy协议实验、M3 seed854附件3单模型和M1 seed1111解释模型具有不同作用。仓库没有齐备论文全部多种子原始run；缺失证据不得用其他seed或协议的数字代替。详见[实验结果与证据边界](docs/实验结果与证据边界.md)。

完整版论文暂不放入仓库；本仓库初始为私有。上游许可证已保留，原创部分暂未指定开源许可证。
