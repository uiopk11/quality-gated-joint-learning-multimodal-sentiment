## 四种 mask 与坐标

共同输入使用 `text_bert[3,50]`，A/V 为 50×74、50×35。A/V 标准化只在原 train 的有效正文且非整行全零的位置拟合逐通道均值和总体标准差：float64、ddof=0，有效行内部零坐标参与统计，小于 1e-6 的标准差使用尺度 1。原生/人工全零行、特殊位和 padding 保持零。完整和缺失视图共享参数，参数保存进模型 buffers 和元数据；valid/test/附件三加载已冻结统计，不重新拟合。

| 符号 | 含义 | 用途 |
|---|---|---|
| `P` | 正文有效范围，不含 CLS、SEP、padding | 确定长度与合法遮蔽范围 |
| `M_m` | 模态 m 的人工遮蔽，`True` 表示移除 | 构造输入、统计人工缺失率 |
| `O_m` | 原始正文的可观测代理：文本非 UNK；A/V 整行非全零 | 观测保护、区分原生不可观测与人工缺失 |
| `S_m = P ∧ M_m ∧ O_m` | 可靠重建目标的支持范围 | 仅用于训练恢复监督，不能替代 M 统计缺失率 |

`O` 是工程代理，不证明零行或 UNK 的成因。非全零 A/V 行内部的零坐标正常参与监督；整条原生全零模态仍参加情感预测监督，其恢复支持为空。空支持由训练器安全归约为零。

- 正文长度 `L = sum(text_bert attention mask) - 2`，不按 A/V 非零行数推算。
- 磁盘人工掩码形状为 `[N, 3, 50]`，模态顺序 T/A/V；正文 0 基位置 j 对应原始位置 j+1。元数据区间为正文坐标的左闭右开 `[start, end)`。
- 文本在送入 BERT **之前**将 M 选中的 token 替换成同一词表的 UNK；attention、segment IDs、CLS、SEP 和 padding 不变。
- A/V 被选行整行置零；模型输入去掉原始第 0 位后左移，末尾补零，相关掩码同步左移。缺损不删行、不压紧、不改变长度。
- 文本恢复支持为去 CLS 后的 49 槽；A/V 支持为左移后的 50 槽，再随 packed LSTM 输出裁长，不能截掉有效正文。
- 缺损预测不得读取完整 raw_text、未遮蔽文本表示或模拟器原始真值；需要观测状态时只能从当前输入按推理可用规则计算。

人工实际率为每模态 `sum(M_m)/L`；三模态槽位率为 `sum(M)/(3L)`。总体微平均采用总缺失位置数除以总正文位置数，并与逐样本率均值区分。每个特征行计一个位置，不按 74/35 个标量维度计数。

## 主混合配方

完整冻结配置见 [recipe.json](../resources/missing_data/mix_v1/recipe.json)，实现见 [generator.py](../src/data/construction/generator.py)。这些是工程覆盖配置，不是官方规定或已验证最优比例。

1. 每个划分先分配 `NONE/TAV/OTHER = 20%/60%/20%`；OTHER 再按 `T/A/V/TA/TV/AV` 尽量均分。字母表示追加受损模态，TA 不是删除两种整模态。
2. 每种受损集合内部将基准率 `0.10/0.20/0.40/0.60` 尽量均分；形态按单段 1/3、多段 2/3 分配；多模态集合按共同缺口 75%、共同＋附加尝试 25% 分配。
3. 上述各层使用最大余数法，余数并列按配置列出的类别顺序处理，再用独立随机流分配给样本；不强行均衡所有因素的全量交叉组合。

基准遮蔽数：`r=0 → k=0`；`r>0 且 L≥2 → k=min(L-1,max(1,floor(rL+0.5)))`；`L≤1 → k=0` 并记录退化。r 表示受损模态或共同缺口的基准率，附加、取整和保护会改变最终实际率；80% 只出现在配对压力条件中。

单段长度为 k。多段令 `B_max=min(k,L-k+1)`，在 `2…B_max` 均匀选段数；不可行时回退单段。将 k 均匀分成 B 个正整数段长，段间至少保留一个位置。预留 B−1 个段间空白后，用 stars-and-bars 在剩余空白的 B+1 项弱组合中均匀抽样；首尾可为零。段长允许为 1，也明确覆盖长度大于 1 的区间。

多模态先共用同一组基准区间。需要附加时，均匀选一个受损模态，令 `d_max=min(3,floor(k/4),L-1-k)`；可行时均匀抽取 1…d_max 的长度。在不重叠共同缺口且满足观测保护的起点中均匀选择；不可行则逐步缩短，最终可不追加。附加与共同缺口允许邻接，统计前合并相邻区间；失败不得记为实际“共同＋附加”。

对原本有观测的每个受损模态，至少保留一个原始可观测位置。每个 k 最多尝试 32 个候选，失败后共同 k 减 1，直至成功或为 0；多模态共同重抽/减量，不分别修改基准 k。原本无观测的模态只免除此保护，仍按计划生成 M。主混合集始终保留全部样本，回退、减量、附加失败及实际形态逐条记录。

根种子为 `20260924`，与模型种子分开；随机数为 NumPy `Generator(PCG64)`。由 `root_seed/recipe_id/family/split/index/id/condition/stage` 的规范 UTF-8 JSON（排序键、紧凑分隔符、ensure_ascii=False、allow_nan=False）计算 SHA256，取前 16 字节大端整数派生种子。配额阶段用 `index=-1,id=""`；其余用原始身份。不同划分、条件、阶段和探索性开关互不扰动。

## 配对评价

各模型共享条件，同一面板只比较其全部条件共同适用的 ID；这些视图不参加训练，不是多套独立训练任务。

| panel | 条件与固定控制 | valid/test 共同 N |
|---|---|---:|
| `complete` | 无新增遮蔽 | 728/727 |
| `modality` | `center_r40_{T,A,V,TA,TV,AV,TAV}`，各受损模态 40%，同一居中单段 | 721/726 |
| `rate` | TAV 同步居中单段，0/20/40/60/80%；0 引用 complete | 713/719 |
| `position` | TAV 40% 单段，`head/center/tail_r40_TAV` | 708/717 |
| `shape` | L≥20，TAV 各缺 8 位置：`shape_1x8/2x4/4x2/8x1` | 409/397 |
| `synchrony` | `sync_shared_r40` 与 `sync_independent_r40`，TAV 各 40% 单段，随机起点 | 724/727 |

头/中/尾起点为 `0、floor((L-k)/2)、L-k`。形态条件固定段长，沿用有段间空白的放置算法；8×1 的八个点互不相邻。独立同步条件各模态独立抽起点，允许偶然重叠。

固定位置只有规定起点；随机形态/同步条件最多抽 32 次。若预设数量、形状与观测保护不能同时满足，记为不适用，**不减量、不换形状**；主集不丢样本。条件可适用数不能代替面板共同 N，排除理由与 ID 见 [valid 面板](../resources/missing_data/mix_v1/panels/valid.json)、[test 面板](../resources/missing_data/mix_v1/panels/test.json)。

模态面板单/多模态之间总损失量不同；率面板同时改变单段长度；主混合分组还可能混入其他因素。按这些边界解释结果，不能将所有差异都归给单一因素。

## 探索性补充的来源边界

`exploratory_a3like` 参考过附件三既有缺失形态观察，来源历史保留在[附件三只读审计](../reproducibility/data_audits/20260924/attachment3/README.md)及[原分析报告](../reproducibility/observations/附件三分析报告.md)，文件指纹见 [exploratory_recipe.json](../resources/missing_data/mix_v1/exploratory_recipe.json)。生成器不读取附件三 PKL，也不复制其逐样本掩码或内容；不能因此声称设计从未参考附件三。

该补充集目标 10% 无新增缺失、90% TAV 同步，受损率 0.10/0.20/0.30/0.40 尽量均分；从正文无放回均匀抽 k 个位置，允许相邻，事后合并统计，不限制最长段。沿用主集取整、观测保护及 32 次后共同减量规则，不增加额外单模态缺口。

只在模型权重和主评价阈值冻结后单独评价；补充 valid/test 均不用于训练、早停、选权重、调参、阈值校准或主实验汇总。其准确率不能换算成附件三的预计正确条数；后续若依据它开发模型，应明确标为探索性开发结果。

## 读取与复核命令

在 `problem2_solution` 目录、已有虚拟环境中运行：

```powershell
python -X utf8 run.py verify
python -X utf8 run.py data inspect --split valid --family main_mixed --condition mixed_v1_s0 --index 0
# 仅在确需另存重建时运行，--output 必须指向尚不存在的目录
python -X utf8 run.py data build --output .\resources\missing_data\mix_v1_rebuild_new
```

`run.py verify` 只读核验现有资源及冻结绑定，不刷新任何验收文件。历史 `dataset_construction verify --reproduce` 会刷新验收文件，不能用于本次日常复现检查；如需构造复核，应在新的输出目录使用 build。`build` 自动完整验收、拒绝覆盖，必须显式传入新 `--output`；`--no-exploratory` 仅关闭补充视图。默认源为 `resources/data/attachment2/aligned_50.pkl`，inspect 的默认产物目录为 `resources/missing_data/mix_v1`。各子命令的 `--help` 给出全部选项。

`inspect --index` 使用原始划分 index；配对检查还需 `--family paired --condition 实际条件ID --panel 面板名`，先确认该 index 属于公开共同交集。`-X utf8` 避免 Windows 中文输出乱码。

```python
from src.data.construction import MissingDataset

dataset = MissingDataset(
    artifact_dir="resources/missing_data/mix_v1",
    source_path="resources/data/attachment2/aligned_50.pkl",
    split="train", family="main_mixed", condition_id="mixed_v1_s0",
    include_reference=True,
)
sample = dataset[0]
support = dataset.supervision(0)
```

默认 sample 返回 PyTorch 张量形式的遮后 `text/audio/vision/audio_lengths/vision_lengths/labels/id/index`；`numpy_item(position)` 返回 NumPy 副本。只有 train/main_mixed 可请求 `include_reference=True`（原始输入在 `sample["reference"]`）或 `supervision(position)`；监督字典与预测输入分开。

`support["reconstruction"]` 包含 text/audio/vision；`supervision(..., audio_steps=..., vision_steps=...)` 可裁到 LSTM 输出长度。配对除 complete 外必须显式传 `panel`，否则拒绝读取；筛选后的 position 不等于返回的原始 index。

读取器核对已通过验收、manifest 绑定、源数据、词表、构造代码及产物指纹；来源变化须生成新版本，不能手改验收状态或指纹绕过。
