# 问题一：质量门控分层词元对齐模型（QG-HTA）建模与时序对齐机制设计

## 1 文档用途与结论

依据正式题面、`项目总览.md`、`解答/第一问/`中的最终代码与配置，以及2026年9月24日完成的100条正式输出整理。本文档既给出可以直接转写为论文的模型框架，也明确每项结论对应的结果文件和当前仍需补齐的人工验证。

问题一建立**质量门控分层词元对齐模型**（Quality-Gated Hierarchical Token Alignment，简称 **QG-HTA**）。模型以官方文本为不可变语义主轴，以真实视频播放时间为物理主轴，通过“模态质量测量—文本语音一致性评分—分层对齐决策—自然词时间区间构造—WordPiece时间继承—区间内音视频汇聚—双视图标准化”完成三模态特征构建。该名称突出本题真正的建模内容：不是将BERT、OpenSMILE和OpenFace简单拼接，而是根据样本质量自适应选择完整、局部或无词级对齐，并以显式掩码保存不确定性。

文本模态使用冻结的 `bert-base-uncased` 最后一层表示；语音模态使用 OpenSMILE 的65维 ComParE 2016 帧级底层描述符及9维关键声学量一阶变化率；视觉模态使用 OpenFace 的35维视线、头姿和面部动作单元特征。辅助 Whisper ASR 只用于检测有效语音、核验官方文本与实际语音的一致性并提供候选时间锚点，不替换题目给定文本。

最终100条样本全部生成特征并通过自动完整性审计。固定对齐视图为文本 `(50,768)`、语音 `(50,74)`、视觉 `(50,35)`；固定未对齐视图为文本 `(50,768)`、语音 `(500,74)`、视觉 `(500,35)`。最终实际对齐分支为：完整片段 MFA 26条、ASR定位窗口内 MFA 40条、MFA候选降级为局部 ASR 时间戳11条、直接局部 ASR 时间戳2条、不进行词级对齐21条。

## 3 问题定义与建模目标

### 3.1 输入与输出

输入为附件1的100条英文原始视频及 `label-100.xlsx`。一条样本由 `video_id` 和 `clip_id` 联合确定，代码将其规范化为

\[
\mathrm{sample\_id}=\mathrm{video\_id}\;\Vert\;\texttt{\_\_}\;\Vert\;\mathrm{clip\_id}.
\]

对每条样本输出：

1. 文本、语音、视觉三模态时序特征；
2. 以BERT WordPiece为主轴的长度50对齐视图；
3. 以正式播放时间轴为基准的长度500音视频未对齐视图；
4. 自然词、BERT词元、音频帧和视频帧之间的映射；
5. 文本注意力、人声存在、文本—ASR匹配、语音有效、视觉有效和跨模态有效等掩码；
6. 原始文件校验、媒体信息、工具版本、配置、日志和异常原因。

### 3.2 建模难点

问题一的核心困难不是简单调用预训练模型，而是处理三种不一致：

- 采样尺度不一致：文本按词元组织，语音约每10 ms产生一帧，视觉按视频帧率采样；
- 内容可能不一致：部分视频可能静音、无人声、包含额外话语，或实际语音与官方文本错配；
- 有效性不一致：某一词区间可能有语音帧但无人脸，或有BERT表示但没有可靠音视频时间锚点。

因此不能对全部样本无条件执行全文强制对齐，也不能用全零向量同时表示填充、缺失和质量失败。最终模型先评估内容一致性，再选择对齐层级，并使用独立掩码表达不同缺失原因。

### 3.3 主要符号

| 符号 | 含义 | 维度或取值 |
| --- | --- | --- |
| $i$ | 样本索引 | $i=1,\ldots,100$ |
| $T_i$ | 第$i$条样本的官方英文文本 | 字符串，保持题目原值 |
| $O_i=(o_{i,1},\ldots,o_{i,N_i})$ | 官方自然词序列 | $N_i$个自然词 |
| $Z_i=(z_{i,1},\ldots,z_{i,L_i})$ | BERT WordPiece序列 | $L_i$个词元，含特殊词元 |
| $\pi_i(j)$ | 第$j$个WordPiece所属的自然词编号 | $-1$或$0,\ldots,N_i-1$ |
| $x_i[n]$ | 16 kHz单声道离散音频信号 | 幅值 |
| $D_i$ | MP4正式播放时长 | 秒 |
| $\mathbf h_{i,j}^{(t)}$ | 第$j$个文本词元特征 | $\mathbb R^{768}$ |
| $\mathbf a_{i,r},t_{i,r}^{(a)}$ | 第$r$个语音帧特征及中心时刻 | $\mathbb R^{74}$，秒 |
| $\mathbf v_{i,q},t_{i,q}^{(v)}$ | 第$q$个视觉帧特征及时间戳 | $\mathbb R^{35}$，秒 |
| $I_{i,n}=[b_{i,n},e_{i,n}]$ | 第$n$个官方自然词的可靠时间区间 | 秒；不可靠时为空集 |
| $S_i$ | 官方文本与ASR文本的一致性分数 | $[0,1]$ |
| $g_i$ | 样本的门控对齐决策 | 五类实际分支之一 |
| $\mathbf m_i^{(\cdot)}$ | 文本、语音、视觉、匹配及跨模态掩码 | 0或1 |
| $T$ | 对齐词元轴最大长度 | $T=50$ |
| $K$ | 未对齐音视频时间箱数 | $K=500$ |

除特别说明外，上标 $(t)$、$(a)$、$(v)$ 分别表示文本、语音和视觉模态；自然词索引使用$n$，BERT词元索引使用$j$，语音帧索引使用$r$，视觉帧索引使用$q$，避免把“词”“词元”和“帧”混为同一层级。

### 3.4 QG-HTA模型的数学结构

对第 $i$ 条样本，记官方文本为 $T_i$，原始音频信号为 $A_i(t)$，原始视频帧序列为 $V_i(t)$，正式播放时长为 $D_i$。QG-HTA可写为以下复合映射：

\[
\mathcal F_i=
\mathcal S\Bigl(
\mathcal P\bigl(
\mathcal H(T_i,A_i),
\mathcal E_T(T_i),
\mathcal E_A(A_i),
\mathcal E_V(V_i)
\bigr)
\Bigr),
\]

其中：

- \(\mathcal E_T\) 为BERT文本特征映射，输出768维词元表示；
- \(\mathcal E_A\) 为OpenSMILE声学映射，输出带时间戳的74维帧特征；
- \(\mathcal E_V\) 为OpenFace视觉映射，输出带时间戳的35维帧特征；
- \(\mathcal H\) 为质量门控与分层对齐算子，根据人声活动、一致性分数、首尾锚点和MFA核验结果选择对齐分支；
- \(\mathcal P\) 为跨模态区间聚合算子，将同一可靠自然词区间中的语音帧和视觉帧分别汇聚，并映射至该词对应的全部WordPiece；
- \(\mathcal S\) 为标准化算子，产生长度50的词元对齐视图、长度500的音视频时间视图及配套掩码。

最终输出写为

\[
\mathcal F_i=
\left\{
\mathbf X_i^{50},
\mathbf A_i^{50},
\mathbf V_i^{50},
\mathbf A_i^{500},
\mathbf V_i^{500},
\mathbf M_i,
\mathbf R_i
\right\},
\]

其中前三项是三模态词元对齐特征，后两项是完整正式时间轴上的音视频特征，\(\mathbf M_i\) 为多类有效性掩码，\(\mathbf R_i\) 为从标准化序列位置回溯至自然词、原始时间区间和帧索引的记录。该定义同时回答了“提取什么特征”“何时允许对齐”“怎样建立跨模态时间对应”以及“异常位置如何保留”四个建模问题。

模型首先为样本构造质量状态向量

\[
\mathbf q_i=
\left(r_i^{\mathrm{act}},,n_i^{\mathrm{asr}},,
F_{1,i},,S_{\mathrm{char},i},,S_i,,
c_i^{\mathrm{left}},,c_i^{\mathrm{right}},,
ho_i^{\mathrm{MFA}}\right),
\]

其中依次表示信号活动比例、ASR有效词数、词级F1、字符相似度、综合一致性、首词锚点是否可靠、末词锚点是否可靠和MFA词序列匹配率。门控算子根据 $\mathbf q_i$ 输出 $g_i$，而非直接根据单一分数强制决定对齐。

对可靠自然词区间，定义跨模态对应关系

\[
\mathcal R_i=
\left\{
(j,r,q);\middle|\;
\pi_i(j)=n,
t_{i,r}^{(a)}\in I_{i,n},
t_{i,q}^{(v)}\in I_{i,n},
m_{i,r}^{(a)}m_{i,q}^{(v)}=1
\right\}.
\]

因此，三模态“对齐”不是要求三种特征的采样点数量相同，而是要求它们能够通过同一个自然词区间 $I_{i,n}$ 映射到相同的BERT词元位置。模型遵守以下约束：

\[
0\le b_{i,n}<e_{i,n}\le D_i,
\qquad
e_{i,n}\le b_{i,n+1},
\]

\[
I_{i,n}=\varnothing
\Longrightarrow
\bar{\mathbf a}_{i,n}=\mathbf 0,
\quad
\bar{\mathbf v}_{i,n}=\mathbf 0,
\quad
m_{i,n}^{(c)}=0.
\]

第一组约束保证词区间位于正式播放时间内且按语序单调；第二组约束规定无法可靠对齐时不得伪造时间关系，而必须以零填充和掩码共同表达不确定性。

## 4 总体建模思路与流程

QG-HTA由五个相互衔接的层次组成。论文应按“输入—数学运算—输出—进入下一层的接口”展开，而不是按软件调用顺序罗列工具。

| 模型层次 | 输入 | 核心运算 | 输出 |
| --- | --- | --- | --- |
| 模态表征层 | 官方文本、真实音轨、真实画面 | BERT、OpenSMILE、OpenFace特征映射 | 带原始顺序或时间戳的768/74/35维特征 |
| 质量测量层 | 音频信号、官方词、ASR词 | 信号活动检测、顺序词匹配、数字等价规范化、一致性评分 | 人声状态、匹配掩码、分数与ASR候选锚点 |
| 分层对齐层 | 质量指标与候选锚点 | 完整MFA、窗口化MFA、局部ASR时间戳或无词级对齐 | 官方自然词的可靠时间区间或明确的不可对齐标记 |
| 跨模态映射层 | 自然词区间、音频帧、视频帧、WordPiece | 区间筛选、有效帧均值汇聚、自然词到子词的时间继承 | 同一词元位置上的文本、语音、视觉表示及掩码 |
| 标准化与追溯层 | 全长词元序列与完整音视频时间轴 | 长度50截断/填充、500步等时长重采样、记录映射 | 双视图特征、时间边界、全量表和可复现文件 |

整体流程可概括为：

> 样本清单与媒体审计 → 音频分离 → Whisper辅助质量审计 → 官方文本BERT编码 → OpenSMILE语音帧特征 → OpenFace视觉帧特征 → 一致性门控 → 窗口化MFA或局部ASR对齐 → 词区间聚合与WordPiece映射 → 长度50对齐视图和长度500未对齐视图 → 掩码与追溯文件 → 全量完整性审计。

具体步骤如下。

1. 从标签表读取 `video_id`、`clip_id`、`text`、`label` 和 `annotation`，核对100行标签与100个MP4文件是否一一对应。
2. 使用 FFprobe 读取正式播放时长、帧率、音视频流信息；计算原视频 SHA256。所有原始视频和标签只读。
3. 使用 FFmpeg 提取16 kHz、单声道PCM音频，供ASR、OpenSMILE和MFA使用。
4. 对真实音轨运行 Whisper-small，得到辅助转写与词级时间戳；同时计算峰值、均方根能量和信号活动比例。
5. 将ASR词序列与官方文本比较，计算一致性分数，选择完整MFA候选、局部ASR时间戳或无词级对齐。
6. 使用冻结的 `bert-base-uncased` 对官方文本编码；官方文本始终保留，不被ASR文本覆盖。
7. 使用 OpenSMILE 提取74维帧级语音特征，使用 OpenFace 提取35维帧级视觉特征，并保存真实时间戳和有效性。
8. 对高一致性且首尾锚点可靠的样本，在ASR定位窗口内运行MFA；对中等一致性或首尾锚点不足样本，仅保留连续可靠匹配词的ASR时间戳；低一致性或无人声样本不建立文本词级音视频对应。
9. 在每个可靠自然词时间区间内分别对有效语音帧和视觉帧取均值，并将自然词结果映射到其WordPiece。
10. 生成固定长度的 `aligned_50` 与 `unaligned_500`，同步保存掩码、时间轴、对齐表、元数据和日志。
11. 对100条输出检查覆盖、形状、字段顺序、有限值、时间单调性、掩码逻辑、源文件路径及追溯关系。

这一流程的核心约束是：**文本内容由官方标签决定，时间坐标由正式播放音视频决定，二者只有在质量门控通过的位置才建立词元级联系。** 因而，高质量样本获得精细词级三模态对应，局部可靠样本仅保留可信词段，错配或静音样本仍保留官方文本和完整音视频视图，但不伪造跨模态对应关系。

论文中可将求解过程写成以下伪代码。

```text
算法1  QG-HTA三模态特征提取与时序对齐
输入：100条视频及官方文本、标签；阈值τL、τH；标准长度T=50、K=500
输出：每条样本的三模态双视图、掩码、时间映射和全量汇总

for 每条样本 i do
    1. 核验sample_id、原视频和官方记录，读取正式播放时长Di
    2. 提取16 kHz单声道音频；计算峰值、RMS和信号活动比例
    3. Whisper生成辅助词序列和候选词时间戳
    4. 计算词级F1、字符相似度及Si，确定第一阶段门控类别
    5. BERT编码官方文本；OpenSMILE/OpenFace提取带时间戳帧特征
    6. if 高一致性且首尾锚点可靠 then
           构造窗口Wi，在窗口内运行MFA并核验结果
           若核验失败则降级为局部ASR时间戳
       else if 中等一致性 then
           仅保留连续可靠匹配词的ASR时间戳
       else
           不建立文本词级音视频对应
    7. 对每个可靠自然词区间汇聚有效语音帧和视觉帧
    8. 通过word_ids将自然词区间及音视频向量扩展到WordPiece
    9. 同步截断或填充为aligned_50；按正式时间轴生成unaligned_500
   10. 保存独立掩码、逐词/逐词元映射、质量指标和追溯信息
end for
合并100条特征并执行覆盖、形状、有限值、时间单调性和字段一致性审计
```

## 5 原始样本处理与质量审计

### 5.1 样本完整性

标签表中的每行记录被转换为唯一 `sample_id`，同时检查：视频存在、文本非空、联合编号无重复、数据目录中不存在没有标签的额外MP4。正式清单 `manifest.csv` 含100条记录，最终汇总 `all_samples.csv` 同样含100条，二者样本编号集合一致。

### 5.2 正式播放时间轴

部分MOSEI视频包含MP4 `edit list`，底层存储轨可能含正式播放区间之外的预留帧。模型以 FFmpeg 和 OpenFace 共同解释的正式播放时间轴为准，不把隐藏预留帧纳入词级对齐。媒体元数据同时保留正式播放时长、帧率、估计正式帧数和底层存储帧信息，便于核验。

本批100条媒体的实际探测时长范围为2.257至29.288021秒，与题面概述的2.648至34.567秒不完全一致。论文应写明“所有时间特征以实际MP4媒体探测结果为准”，不可擅自修改原始文件来迎合概述范围。

### 5.3 信号活动与辅助ASR

对长度为 $N_i^{(x)}$ 的音频信号 $x_i[n]$，计算峰值幅度和均方根幅度

\[
p_i=\max_n|x_i[n]|,
\qquad
r_i=\sqrt{\frac{1}{N_i^{(x)}}\sum_{n=1}^{N_i^{(x)}}x_i[n]^2},
\]

并转换为

\[
L_i^{\mathrm{peak}}=20\log_{10}(\max(p_i,10^{-12})),
\qquad
L_i^{\mathrm{RMS}}=20\log_{10}(\max(r_i,10^{-12})).
\]

把音频划分为短时帧，记第$u$帧的分贝能量为 $E_{i,u}$，以低分位帧能量估计噪声底 $E_i^{\mathrm{noise}}$，定义活动指示量与活动比例

\[
\eta_{i,u}=\mathbf 1
\left(E_{i,u}>E_i^{\mathrm{noise}}+12\ \mathrm{dB}\right),
\qquad
r_i^{\mathrm{act}}=\frac{1}{U_i}\sum_{u=1}^{U_i}\eta_{i,u}.
\]

峰值低于 -50 dBFS 时可直接视为近似静音。综合信号活动与Whisper输出，定义人声存在标志

\[
c_i^{\mathrm{speech}}=
\mathbf 1\left(
r_i^{\mathrm{act}}\ge0.02
\right)
\mathbf 1\left(n_i^{\mathrm{asr}}\ge1\right).
\]

当

\[
r_i^{\mathrm{act}}\ge 0.02
\]

且 Whisper 至少输出1个有效词时，记为存在可用语音；否则进入无词级对齐分支。能量指标用于发现静音和低活动信号，Whisper用于提供候选词和时间戳，二者均不是最终文本模态。

Whisper-small只承担质量核验和时间定位。当前100条结果中8条被判定为无人声或无有效语音；所有样本的 `detected_language` 均为 `not_reported`，因此论文不得声称已经基于Whisper完成语言类别统计。

## 6 三模态情感特征定义与提取

### 6.1 文本模态

设官方规范化自然词序列为

\[
O=(o_1,o_2,\ldots,o_N).
\]

使用 `bert-base-uncased` 的快速分词器将自然词映射为包含 `[CLS]`、WordPiece和 `[SEP]` 的词元序列

\[
Z=(z_1,z_2,\ldots,z_L).
\]

冻结BERT参数，取最后一层隐藏状态作为文本情感语义表示：

\[
\mathbf{h}^{(t)}_j=\mathrm{BERT}_{-1}(Z)_j\in\mathbb{R}^{768}.
\]

若第$l$层的输入为 $\mathbf H^{(l-1)}$，其自注意力计算可概括为

\[
\mathbf Q=\mathbf H^{(l-1)}\mathbf W_Q,
\quad
\mathbf K=\mathbf H^{(l-1)}\mathbf W_K,
\quad
\mathbf V=\mathbf H^{(l-1)}\mathbf W_V,
\]

\[
\mathrm{Attention}(\mathbf Q,\mathbf K,\mathbf V)
=\mathrm{softmax}\left(\frac{\mathbf Q\mathbf K^\top}{\sqrt{d_k}}\right)\mathbf V.
\]

本题不重新训练BERT参数，而是把预训练模型视为固定映射 $\mathcal E_T$。这样问题一只定义可复现的文本表征，不使用附件1的100条标签微调，避免在小样本上引入额外训练不确定性。

分词器的 `word_ids` 保存词元 \(z_j\) 到自然词 \(o_i\) 的映射。特殊词元的 `word_id=-1`，有文本表示但没有自然对应的音视频区间。BERT内部最大长度为512；之后统一构造长度50的标准视图。

### 6.2 语音模态

使用 OpenSMILE 2.6.0 的 `ComParE_2016 / LowLevelDescriptors` 提取65维帧级底层描述符，实际帧窗约60 ms、帧移约10 ms。特征覆盖基频、发声概率、抖动、闪烁、谐噪比、能量、过零率、频谱通量以及谱形相关量。

为增强局部动态信息，对9个关键声学量计算相对于时间的一阶变化率：

\[
\Delta x_k(t_i)\approx \frac{\mathrm{d}x_k(t)}{\mathrm{d}t}\bigg|_{t=t_i},
\]

实际离散帧上采用相邻时间点的数值梯度，可写为

\[
\Delta x_{i,r,k}=
\begin{cases}
\dfrac{x_{i,r+1,k}-x_{i,r,k}}{t_{i,r+1}^{(a)}-t_{i,r}^{(a)}},&r=1,\\[6pt]
\dfrac{x_{i,r+1,k}-x_{i,r-1,k}}{t_{i,r+1}^{(a)}-t_{i,r-1}^{(a)}},&1<r<N_i^{(a)},\\[6pt]
\dfrac{x_{i,r,k}-x_{i,r-1,k}}{t_{i,r}^{(a)}-t_{i,r-1}^{(a)}},&r=N_i^{(a)}.
\end{cases}
\]

从而得到

\[
\mathbf{a}_r\in\mathbb{R}^{65+9}=\mathbb{R}^{74}.
\]

9个差分字段为：`F0final_sma`、`voicingFinalUnclipped_sma`、`jitterLocal_sma`、`shimmerLocal_sma`、`logHNR_sma`、`audspec_lengthL1norm_sma`、`pcm_RMSenergy_sma`、`pcm_zcr_sma` 和 `pcm_fftMag_spectralFlux_sma`。完整固定顺序见 `feature_dictionary.csv`。

### 6.3 视觉模态

使用 OpenFace 2.2.0 逐帧提取35维视觉特征：

- 6维左右眼视线方向向量；
- 2维视线角；
- 3维头部平移与3维头部旋转；
- 17维面部动作单元强度；
- 4维关键动作单元出现状态。

设第 \(q\) 个视频帧的特征为

\[
\mathbf{v}_q\in\mathbb{R}^{35}.
\]

只有 OpenFace `success=1` 且置信度不低于0.80、时间戳和数值均有效的帧才参与聚合；其他帧特征置零并令视觉有效掩码为0。各字段含义、量纲和固定次序见 `feature_dictionary.csv`。

第$q$帧的视觉有效性定义为

\[
m_{i,q}^{(v)}=
\mathbf 1(\mathrm{success}_{i,q}=1)
\mathbf 1(c_{i,q}\ge0.80)
\mathbf 1(\mathbf v_{i,q}\ \text{全部有限}),
\]

其中 $c_{i,q}$ 为OpenFace置信度。无有效人脸的帧不参与均值池化，但仍保留原始帧时间位置，从而区分“该时刻不存在画面”和“存在画面但面部特征不可用”。

### 6.4 维度解释边界

自行提取特征采用768/74/35维，张量形状与附件2和附件3接口一致，便于后续统一数据加载；但OpenSMILE/OpenFace字段与附件2可能使用的COVAREP/FACET并非同一特征体系。因此论文只能写“接口形状一致”，不能写“特征语义或数值与附件2完全相同”。

## 7 文本语音一致性门控模型

### 7.1 词序列匹配

设辅助ASR词序列为

\[
A=(a_1,a_2,\ldots,a_M).
\]

对官方词和ASR词进行小写化及标点剥离，再用顺序匹配确定公共连续片段。只有长度不少于2的连续完全匹配片段才产生可靠词级锚点，孤立偶然匹配不用于对齐。

在核验层，将英文数字词与等值阿拉伯数字转换为相同比较单元，例如 `twelve hundred` 与 `1200` 视为等价。该规范化只参与一致性比较，不修改官方文本、BERT输入、MFA文本、ASR原文或ASR原始时间戳。若多个官方数字词对应一个ASR数字词元，则按官方词顺序等分该ASR词元的时间段。

### 7.2 一致性分数

设可靠匹配比较单元数为 \(C\)，官方比较单元数为 \(N_c\)，ASR比较单元数为 \(M_c\)，则

\[
R=\frac{C}{N_c},\qquad P=\frac{C}{M_c},\qquad
F_1=\frac{2PR}{P+R}.
\]

记规范化后的官方字符序列和ASR字符序列为 $u_i$、$v_i$，以编辑距离 $d_{\mathrm{lev}}$ 定义字符相似度

\[
S_{\mathrm{char},i}
=1-\frac{d_{\mathrm{lev}}(u_i,v_i)}{\max(|u_i|,|v_i|,1)}.
\]

综合词级覆盖与字符级整体相似性，定义

\[
S_i=0.7F_{1,i}+0.3S_{\mathrm{char},i}.
\]

### 7.3 双阈值的无监督确定

为避免依赖人工标签或利用下游情感标签调参，本文仅依据100条样本的一致性得分经验分布确定门控层级。将得分从小到大记为

\[
S_{(1)}\le S_{(2)}\le\cdots\le S_{(100)},
\]

并定义相邻间隔

\[
\Delta_j=S_{(j+1)}-S_{(j)},\qquad j=1,\ldots,99.
\]

QG-HTA本身是两级决策：先判断样本是否具备词级对齐条件，再在可对齐候选中区分局部对齐与完整MFA候选。因此采用与该结构一致的递归最大间隔分割，而不是对两个阈值同时进行无监督网格搜索。

第一层在全部100条得分中寻找最大相邻间隔。最大间隔位于第21和第22个有序得分之间：

\[
S_{(21)}=0.292073,\qquad S_{(22)}=0.672094,
\]

间隔宽度为0.380021，对应自然断点中值为

\[
\tau_L^*=\frac{S_{(21)}+S_{(22)}}{2}=0.482084.
\]

该断点将21条低一致性样本与79条可对齐候选分开。第二层只在这79条候选中再次寻找最大相邻间隔，断点位于原全体排序的第23和第24个得分之间：

\[
S_{(23)}=0.719559,\qquad S_{(24)}=0.781176,
\]

由此得到

\[
\tau_H^*=\frac{S_{(23)}+S_{(24)}}{2}=0.750368.
\]

第二层进一步得到2条局部对齐候选和77条完整MFA候选。由于上述断点均位于没有观测样本的空白区间内，实际门控结果对区间内部的具体取值不敏感。保持当前100条样本分支完全不变的阈值稳定区间为

\[
\tau_L\in(0.292073,0.672094],\qquad
\tau_H\in(0.719559,0.781176].
\]

代码实际采用 \(\tau_L=0.35\)、\(\tau_H=0.75\)。其中0.35位于第一稳定区间内，0.75近似第二自然断点中值；二者与自然断点中值产生完全相同的候选分组，即21条无词级对齐、2条局部ASR时间戳候选和77条MFA候选。低阈值取稳定区间内偏低的代表值，使区间中新出现的边界样本优先保留局部对齐可能，而不会直接丢弃其词级信息；高分样本仍须通过首尾锚点、窗口合法性和MFA词序列核验，才会进入最终完整对齐分支。

因此，这两个阈值应表述为“由一致性得分经验分布的递归最大间隔分割确定、并在稳定空白区间内选取的实现阈值”，而不能称为有监督网格搜索得到的全局最优阈值或适用于任意数据集的普适阈值。该过程不使用情感标签，也不改变官方文本、ASR结果或任何三模态特征。

据此，第一阶段候选门控函数为：

\[
g(S)=
\begin{cases}
\text{MFA候选}, & S\ge \tau_H,\\
\text{局部ASR时间戳}, & \tau_L\le S<\tau_H,\\
\text{无词级对齐}, & S<\tau_L\text{或无有效语音}.
\end{cases}
\]

上式只给出第一阶段候选类别。为避免高分但首尾错位的样本进入错误MFA，第二阶段再引入首尾锚点、窗口范围和MFA核验。设 $c_i^{L},c_i^{R}\in\{0,1\}$ 表示官方首词、末词是否具有可靠ASR锚点，$w_i\in\{0,1\}$ 表示窗口是否合法，$\rho_i^{\mathrm{MFA}}$ 为MFA输出与官方词序列的匹配率，则最终五类门控决策为

\[
g_i=
\begin{cases}
\texttt{full\_mfa},
& S_i\ge\tau_H,\ c_i^Lc_i^Rw_i=1,\ \rho_i^{\mathrm{MFA}}\ge0.90,\ W_i\approx[0,D_i],\\
\texttt{full\_mfa\_windowed},
& S_i\ge\tau_H,\ c_i^Lc_i^Rw_i=1,\ \rho_i^{\mathrm{MFA}}\ge0.90,\ W_i\subset[0,D_i],\\
\texttt{partial\_asr\_timestamp\_fallback},
& S_i\ge\tau_H,\ \text{但锚点、窗口或MFA核验失败},\\
\texttt{partial\_asr\_timestamp},
& \tau_L\le S_i<\tau_H,\ c_i^{\mathrm{speech}}=1,\\
\texttt{no\_word\_alignment},
& S_i<\tau_L\ \text{或}\ c_i^{\mathrm{speech}}=0.
\end{cases}
\]

这一定义表明“门控”是一个可解释的规则决策函数：它不学习新的情感参数，只根据可核验的质量指标决定允许使用哪一级时间对应关系。

需要准确区分“经验分组”与“最终对齐”。递归最大间隔只确定21/2/77的第一阶段候选分组；77条MFA候选还要接受首尾锚点、窗口范围和MFA词序列核验，最终才形成26条完整片段MFA、40条窗口化MFA、11条局部回退、2条直接局部对齐和21条无词级对齐。现有人工检查仅用于典型样本语义核验，不参与双阈值计算，也不应被表述为阈值标签或监督调参数据。

## 8 分层时序对齐模型

### 8.1 窗口化MFA

高一致性样本首先检查官方首词和末词是否都有可靠ASR锚点。设首词ASR起点为 \(s_1\)，末词ASR终点为 \(e_N\)，正式播放时长为 \(D\)，边界余量为 \(\delta=0.03\) 秒，则MFA候选窗口为

\[
W=[\max(0,s_1-\delta),\min(D,e_N+\delta)].
\]

对第$i$条样本进一步写为

\[
\ell_i=\max(0,s_{i,1}-\delta),
\qquad
u_i=\min(D_i,e_{i,N_i}+\delta),
\qquad
W_i=[\ell_i,u_i].
\]

仅截取 $W_i$ 内的音频用于MFA。若MFA在局部窗口中给出第$n$个官方词区间 $[\tilde b_{i,n},\tilde e_{i,n}]$，则将其平移回正式播放时间轴：

\[
b_{i,n}=\ell_i+\tilde b_{i,n},
\qquad
e_{i,n}=\ell_i+\tilde e_{i,n}.
\]

若窗口与完整音频基本一致，实际分支记为 `full_mfa`；若片段前后存在额外内容而窗口被裁窄，记为 `full_mfa_windowed`。窗口只用于估计官方词时间，不会从最终未对齐音视频视图中删除窗口外内容。

MFA输出词序列还需与官方词序列比较，匹配率必须不低于0.90。首尾锚点不足、窗口无效、TextGrid缺失或词序列匹配率不足时，不强行接受MFA，而降级为 `partial_asr_timestamp_fallback`。

### 8.2 局部ASR时间戳

中等一致性样本以及MFA候选降级样本，仅为连续可靠匹配的官方词赋予ASR时间区间。设顺序匹配给出的官方词到ASR词映射为 $\mu_i(n)$，可靠连续匹配词集合为 $\mathcal C_i$，则

\[
I_{i,n}=
\begin{cases}
[s_{i,\mu_i(n)}^{\mathrm{ASR}},
e_{i,\mu_i(n)}^{\mathrm{ASR}}],&n\in\mathcal C_i,\\
\varnothing,&n\notin\mathcal C_i.
\end{cases}
\]

集合 $\mathcal C_i$ 只保留长度至少为2的连续精确匹配片段，避免单个高频词偶然相同造成错误时间锚点。未可靠匹配词仍保留BERT表示，但其对齐语音、视觉向量置零，相应有效掩码为0。

### 8.3 无词级对齐

低一致性、无人声或无法确认官方文本对应关系的样本不建立文本—音视频词级对应。其长度50文本序列仍由官方文本BERT表示构成；对齐语音和视觉位置置零并由掩码标记。真实音视频信息不删除，完整保存在长度500的未对齐视图中。

### 8.4 自然词到WordPiece的时间继承

若自然词 \(o_i\) 被拆成若干WordPiece

\[
o_i\rightarrow(z_{i,1},z_{i,2},\ldots,z_{i,r_i}),
\]

则所有子词继承父词的同一可靠区间 \(I_i=[b_i,e_i]\)，并共享在该区间聚合得到的语音和视觉向量。`[CLS]`、`[SEP]` 和填充词元不伪造时间戳。

用 $\pi_i(j)$ 表示第$j$个WordPiece对应的自然词编号，则词元时间区间为

\[
J_{i,j}=
\begin{cases}
I_{i,\pi_i(j)},&\pi_i(j)\ge0\ \text{且}\ I_{i,\pi_i(j)}\ne\varnothing,\\
\varnothing,&\text{其他情况}.
\end{cases}
\]

相应的词元级音视频表示满足

\[
\mathbf h_{i,j}^{(a)}=
\bar{\mathbf a}_{i,\pi_i(j)},
\qquad
\mathbf h_{i,j}^{(v)}=
\bar{\mathbf v}_{i,\pi_i(j)},
\]

仅当 $J_{i,j}$ 非空且区间内存在对应有效帧时成立；否则对应向量置零并由掩码注明原因。

### 8.5 词区间内的音视频聚合

设语音帧中心时刻为 \(t_r^{(a)}\)，视觉帧时刻为 \(t_q^{(v)}\)。对可靠词区间 \(I_i=[b_i,e_i]\)，分别定义有效帧集合

\[
\mathcal A_i=\{r\mid b_i\le t_r^{(a)}\le e_i,\ m_r^{(a)}=1\},
\]

\[
\mathcal V_i=\{q\mid b_i\le t_q^{(v)}\le e_i,\ m_q^{(v)}=1\}.
\]

采用均值池化得到词级表示：

\[
\bar{\mathbf a}_i=
\begin{cases}
|\mathcal A_i|^{-1}\sum_{r\in\mathcal A_i}\mathbf a_r,&|\mathcal A_i|>0,\\
\mathbf 0,&|\mathcal A_i|=0,
\end{cases}
\]

\[
\bar{\mathbf v}_i=
\begin{cases}
|\mathcal V_i|^{-1}\sum_{q\in\mathcal V_i}\mathbf v_q,&|\mathcal V_i|>0,\\
\mathbf 0,&|\mathcal V_i|=0.
\end{cases}
\]

这里的零向量必须和有效性掩码联合解释，不能单独视为真实的“零情感特征”。

## 9 标准化时序视图与掩码

### 9.1 对齐视图 aligned 50

对齐主轴为BERT词元轴，固定长度 \(T=50\)：

\[
X^{(t)}\in\mathbb R^{50\times768},\quad
X^{(a)}\in\mathbb R^{50\times74},\quad
X^{(v)}\in\mathbb R^{50\times35}.
\]

长度不足50时在尾部以0填充；长度超过50时保留前49个位置和最后一个特殊词元，完整未截断词元序列仍保存在 `text_full` 等数组和对齐表中。本次100条中95条发生尾部填充，5条标准视图发生截断。

对任意词元序列矩阵 $\mathbf Y_i\in\mathbb R^{L_i\times d}$，定义固定长度算子

\[
\mathcal S_{50}(\mathbf Y_i)=
\begin{cases}
[\mathbf Y_i;\mathbf 0_{(50-L_i)\times d}],&L_i<50,\\
\mathbf Y_i,&L_i=50,\\
[\mathbf Y_i[1{:}49];\mathbf Y_i[L_i]],&L_i>50.
\end{cases}
\]

最后一种情况保留最后一个特殊词元，避免截断后丢失序列结束标记。同一截断索引同步作用于文本、语音、视觉、时间戳和全部词元级掩码，保证不同模态的位置仍一一对应。

### 9.2 未对齐视图 unaligned 500

文本仍使用长度50的标准BERT序列。语音和视觉独立地映射到同一个真实时间网格。对时长为 \(D\) 的视频，第 \(k\) 个时间箱定义为

\[
B_k=\left[\frac{kD}{500},\frac{(k+1)D}{500}\right),\qquad k=0,1,\ldots,499.
\]

每个模态分别对落入时间箱的有效帧取均值。令

\[
\mathcal F_{i,k}^{(m)}=
\{j\mid t_{i,j}^{(m)}\in B_{i,k},\ m_{i,j}^{(m)}=1\},
\qquad m\in\{a,v\},
\]

则

\[
\mathbf U_{i,k}^{(m)}=
\begin{cases}
\dfrac{1}{|\mathcal F_{i,k}^{(m)}|}
\displaystyle\sum_{j\in\mathcal F_{i,k}^{(m)}}\mathbf f_{i,j}^{(m)},
&|\mathcal F_{i,k}^{(m)}|>0,\\[8pt]
\mathbf 0,&|\mathcal F_{i,k}^{(m)}|=0,
\end{cases}
\]

空时间箱填0并设置掩码。`unaligned_bin_starts` 和 `unaligned_bin_ends` 保存500个区间边界；自动审计确认各样本区间连续、单调且完整覆盖正式媒体时长。

### 9.3 掩码定义

| 掩码 | 含义 |
| --- | --- |
| `text_attention_mask` | BERT有效输入位置与填充位置 |
| `speech_present_mask` | 对齐词元是否属于确认存在语音的可靠词区间 |
| `official_asr_match_mask` | 官方自然词与ASR是否可靠对应，并扩展到其WordPiece |
| `audio_valid_mask` | 对应词区间内是否存在有效OpenSMILE帧 |
| `vision_valid_mask` | 对应词区间内是否存在有效OpenFace帧 |
| `cross_modal_mask` | 文本、匹配关系、语音和视觉是否同时有效 |
| `unaligned_audio_valid_mask` | 500步时间箱中是否存在有效语音帧 |
| `unaligned_vision_valid_mask` | 500步时间箱中是否存在有效视觉帧 |
| `unaligned_speech_present_mask` | 500步时间箱是否落在ASR词时间范围内 |

跨模态掩码满足

\[
m_{i,j}^{(c)}=
m_{i,j}^{(t)}
m_{i,j}^{(o\leftrightarrow a)}
m_{i,j}^{(a)}
m_{i,j}^{(v)}
\mathbf 1(\pi_i(j)\ge0).
\]

因为各因子均为0—1变量，上式的乘积等价于逻辑“且”。它要求该位置同时是有效文本词元、官方词与ASR可靠对应、区间内存在有效语音帧、区间内存在有效视觉帧且不是特殊词元。由此可得

\[
m_{i,j}^{(c)}\le
\min\left{
m_{i,j}^{(t)},
m_{i,j}^{(o\leftrightarrow a)},
m_{i,j}^{(a)},
m_{i,j}^{(v)}
\right}.
\]

自动审计进一步检查 `cross_modal_mask` 必须是其他模态有效掩码交集的子集。
